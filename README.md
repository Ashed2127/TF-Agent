# TF-Agent

Telegram bot that generates Amharic business ideas using AI and posts them to a channel with owner approval.

## What it does
- Generates business ideas via Telegram bot
- Owner approves/rejects before posting
- Web dashboard for monitoring
- Rotates through 6 business categories

## Setup
```bash
npm install
cp .env.example .env  # Add your API keys
npm start
```

Dashboard: http://localhost:3000
